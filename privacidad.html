Política de privacidad

YT Automatizado · Última actualización: 26 de noviembre de 2026

Quién la usa

YT Automatizado es una herramienta de uso estrictamente personal. Solo la usa su propietario, con sus propias cuentas de Google, YouTube y TikTok. No está abierta al público ni accede a cuentas de otras personas.

Qué datos de Google usa

Con el permiso que el propietario concede al iniciar sesión, la herramienta usa la API de YouTube y la API de YouTube Analytics únicamente para:

  • subir vídeos cortos a los canales del propietario;
  • poner la miniatura de esos vídeos y añadirlos a listas de reproducción de esos canales;
  • leer el nombre y las estadísticas de esos canales y vídeos (visitas, «me gusta», comentarios, retención) para decidir qué clips funcionan mejor.

Dónde se guardan

Los permisos de acceso y las estadísticas se guardan solo en el ordenador del propietario. No se envían a ningún servidor propio, no se venden, no se comparten con terceros y no se usan para publicidad.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
